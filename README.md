
Учебный проект: чат-бот, который помогает заводить привычки, отмечать выполнение, видеть серии (streak) и статистику, получать напоминания. Основная платформа — **ВКонтакте** (бот сообщества).

## Обоснование полезности

Начать привычку просто, удержаться трудно. В исследовании Lally и соавторов (UCL, 2010; 96 участников, 84 дня) привычка становилась автоматической в среднем за 66 дней (от 18 до 254), а один пропущенный день значимо на этот процесс не влиял. Мобильные приложения при этом теряют большинство пользователей в первый месяц: по обзорам 2026 года, медиана возврата на 30-й день для приложений категории health & fitness составляет единицы процентов.

Бот не требует установки отдельного приложения: напоминания приходят в мессенджер, которым человек и так пользуется. Задача проекта — помочь преодолеть первые недели внедрения привычки и вернуться после пропуска.

## Что внутри репозитория

| Файл | Назначение |
|---|---|
| `generate_data.py` | Генератор синтетических данных (воспроизводимый, `seed=42`) |
| `habits_data.csv` | Готовый набор данных: 5 758 строк, 12 колонок |

## Старт

Нужен Python 3.10+. Код проверялся на Python 3.12, pandas 3, numpy 2, matplotlib 3.

```bash
pip install -r requirements.txt

python generate_data.py        # создаёт habits_data.csv
python analysis.py             # печатает метрики и сохраняет графики в charts/
```

Скрипты запускаются из папки, где лежит `habits_data.csv`.

## Данные

**Данные синтетические.** Генератор моделирует работу бота с 1 июля по 31 октября 2026: 71 пользователь, 152 привычки. В модель заложены разная дисциплина пользователей, отток, временные «провалы» у части людей, спад в выходные, постепенное остывание интереса к привычке, влияние серии и напоминаний. Все параметры вынесены в константы в начале `generate_data.py`.

Одна строка — одна запланированная отметка привычки в конкретный день.
У привычек «несколько раз в неделю» строки есть только в запланированные дни (3–4 в неделю).
Для привычек «несколько раз в неделю» серия считается в отметках, а не в днях.

| Колонка | Смысл | Тип / значения |
|---|---|---|
| `user_id` | Пользователь | текст, `U001`…`U072` |
| `date` | Дата отметки | 2026-07-01…2026-10-31 |
| `habit_id` | Привычка | текст, `H0001`… |
| `habit_name` | Название привычки | текст, 24 варианта |
| `category` | Категория | здоровье, спорт, учёба, продуктивность, финансы, сон, другое |
| `target_frequency` | Целевая частота | «ежедневно» или «несколько раз в неделю» |
| `completed` | Выполнено | 1 или 0 |
| `reminder_time` | Время напоминания | `HH:MM`; пусто, если напоминания выключены |
| `reminder_replied` | Была ли реакция на напоминание (любая кнопка) | 1 или 0; пусто, если напоминания нет или доставка не подтверждена |
| `current_streak` | Серия подряд выполненных отметок на конец дня | целое, 0…21 |
| `weekday` | День недели | Пн…Вс |
| `active_habits_count` | Активных привычек у пользователя на эту дату | целое, 1…4 |
