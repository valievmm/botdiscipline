# Бот для отслеживания привычек и дисциплины

Учебный проект: чат-бот, который помогает заводить привычки, отмечать выполнение, видеть серии (streak) и статистику, получать напоминания. Основная платформа — **ВКонтакте** (бот сообщества).

> **Статус:** этап «данные и анализ» завершён, бот находится в разработке.

---

## Зачем это нужно

Начать привычку просто, удержаться трудно. В исследовании Lally и соавторов (UCL, 2010; 96 участников, 84 дня) привычка становилась автоматической в среднем за 66 дней (от 18 до 254), а один пропущенный день значимо на этот процесс не влиял. Мобильные приложения при этом теряют большинство пользователей в первый месяц: по обзорам 2026 года, медиана возврата на 30-й день для приложений категории health & fitness составляет единицы процентов.

Бот не требует установки отдельного приложения: напоминания приходят в мессенджер, которым человек и так пользуется. Задача проекта — помочь пережить первые недели и вернуться после пропуска.

## Быстрый старт

Нужен Python 3.10+. Код проверялся на Python 3.12, pandas 3, numpy 2, matplotlib 3.

```bash
pip install -r requirements.txt

python generate_data.py        # создаёт habits_data.csv (перезаписывает файл)
python analysis.py             # печатает метрики и сохраняет графики в charts/
```

Скрипты запускаются из папки, где лежит `habits_data.csv`.

## Данные

**Данные синтетические.** Генератор моделирует работу бота с 1 июля по 31 октября 2026: 71 пользователь, 152 привычки. В модель заложены разная дисциплина пользователей, отток (больше всего в первые две недели), временные «провалы» у части людей, спад в выходные, постепенное остывание интереса к привычке, влияние серии и напоминаний. Все параметры вынесены в константы в начале `generate_data.py`.

Одна строка — одна запланированная отметка привычки в конкретный день. У привычек «несколько раз в неделю» строки есть только в запланированные дни (3–4 в неделю).

| Колонка | Смысл | Тип / значения |
|---|---|---|
| `user_id` | Пользователь | текст, `U001`…`U072` |
| `date` | Дата отметки | 2026-07-01…2026-10-31 |
| `habit_id` | Привычка | текст, `H0001`… |
| `habit_name` | Название привычки | текст, 24 варианта |
| `category` | Категория | здоровье, спорт, учёба, продуктивность, финансы, сон, другое |
| `target_frequency` | Целевая частота | «ежедневно» или «несколько раз в неделю» |
| `completed` | Выполнено | 1 или 0 |
| `reminder_time` | Время напоминания | `HH:MM`; пусто, если напоминания выключены |
| `reminder_replied` | Была ли реакция на напоминание (любая кнопка) | 1 или 0; пусто, если напоминания нет или доставка не подтверждена |
| `current_streak` | Серия подряд выполненных отметок на конец дня | целое, 0…21 |
| `weekday` | День недели | Пн…Вс |
| `active_habits_count` | Активных привычек у пользователя на эту дату | целое, 1…4 |

Для привычек «несколько раз в неделю» серия считается в отметках, а не в днях.

Проверки логики, пройденные набором данных: нет дублей `(habit_id, date)`; серия равна предыдущей плюс 1 при выполнении и 0 при пропуске; день недели совпадает с датой; у привычки одна категория, одна частота и одно время напоминания.

## Результаты анализа

Значения получены на синтетических данных и показывают, где у трекера привычек узкие места, а не доказывают пользу бота.

- **Выполнение:** 51,8% всех отметок; 55,5% в первые 14 дней у всех пользователей.
- **Retention** (≥1 выполнение за неделю): неделя 1 — 82%, неделя 4 — 59%, неделя 8 — 42%. Эти значения заметно оптимистичнее реальных приложений, прогнозом их считать нельзя.
- **Серии короткие:** у ежедневных привычек медиана максимальной серии 5 дней; две трети серий обрываются на 1–2 дне.
- **Выходные хуже:** суббота на 10,4 п.п. ниже вторника, 95% доверительный интервал [−15,1; −5,1].
- **Серия:** внутри одного пользователя серия накануне ≥ 3 даёт +4…+7 п.п. к шансу выполнить. Наивная разница между группами в несколько раз больше, потому что дисциплинированные люди чаще имеют длинные серии.
- **Не подтвердилось на такой выборке:** эффект напоминаний (интервал включает ноль), различия между категориями, время напоминания, число привычек. Для проверки нужен пилот примерно на 300 пользователей.


## Ограничения

- Данные синтетические: закономерности в них заданы параметрами генератора. Выводы о пользе бота нужно подтверждать пилотом.
- Выборка небольшая (71 пользователь): различия в 2–3 п.п. между группами неотличимы от шума.
